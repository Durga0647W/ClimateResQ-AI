# Project Scope

## In scope
1. Disaster report submission.
2. Quality and completeness checking.
3. GenAI/NLP structured extraction.
4. Cross-source verification using simulated supporting data.
5. Similarity and duplicate detection.
6. Explainable confidence score.
7. Severity and priority assessment.
8. Human verification.
9. Responder dashboard.
10. Database-grounded AI assistant.
11. Simulated 250-report dataset.

## Out of scope for this academic prototype
- autonomous emergency dispatch
- autonomous agents or multi-agent systems
- real emergency notification delivery
- production authentication/authorization
- guaranteed real-time government API feeds
- medical/legal advice
- real disaster claims

## Future extension
Real government/weather APIs, production authentication, multimodal image analysis, GIS maps and deployment can be added after the core prototype.
